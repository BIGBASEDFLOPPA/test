**Краткое описание архитектуры**  
   
    
   
  «Состав» — локальное веб-приложение без сторонних runtime-зависимостей. Браузер отвечает за редактор и SVG; Node.js раздаёт файлы и при необходимости обращается к Cohere.  
   
    
   
  **Хранение и переиспользование SVG**  
   
    
   
  `public/assets/` содержит неизменённые копии исходных векторных объектов. `catalog.json` связывает ID предмета с названием, смысловыми тегами, эталонными размерами и четырьмя вариантами: L/S × главный/фоновый. Подготовка каталога воспроизводится скриптом `scripts/prepare-assets.py`.  
   
    
   
  В браузере исходники загружаются один раз в Map по URL. Сцена хранит ссылки на ID объектов, позиции, углы, роли, порядок слоёв, детализацию, палитру и общий масштаб. Дублирование создаёт новый экземпляр, переиспользующий тот же исходник. Размеры вычисляются из эталонных габаритов с общим коэффициентом, что сохраняет соотношение предметов.  
   
    
   
  **Поток данных**  
1. `public/js/app.js` принимает текст или ручной выбор компонентов.  
2. `public/js/scene.js` сопоставляет текст с локальными темами и тегами. Неуверенный запрос может уйти на `POST /api/interpret` при включённом Cohere.  
3. `server/interpret.mjs` отправляет только короткий текст и пары ID/название, проверяет возвращённые ID, применяет кеш, таймаут и лимиты вызовов. Ключ остаётся на сервере.  
4. Локальный алгоритм выбирает сетку и общий масштаб под формат холста. Редактор меняет модель сцены при ручных операциях.  
5. `assembleSvg` использует ту же сцену для отображения и экспорта: каждый исходник встраивается в отдельную группу с трансформацией; ID определений получают уникальные префиксы. Контуры остаются векторными и редактируемыми.  
   
   
 **Цвета и сохранение**  
   
   Палитра задаёт семантические цветовые слоты. Перекраска заменяет значения цветов, сохраняя геометрию. Фон ограничен слотами surface/accent/ink. Проект сохраняется в JSON и автоматически в localStorage; итоговая иллюстрация скачивается как автономный SVG.  
   
    
 **Проверки**  
   
  `tests/` содержит тесты модели сцены, исходных ассетов, экспорта и серверного API. В тестах Cohere заменён подставным fetch; реальный ключ и квота не используются. Ограничения текущей реализации перечислены в [README.](README.md "README.md")
