**векторный конструктор**  
   
   
 Локальное веб-приложение для сборки иллюстраций из готовых SVG. . Node.js обслуживает файлы и выполняет необязательный текстовый запрос к Cohere. Сборка и npm-зависимости не нужны.  
   
    
   
  **Запуск**  
   
  Требуется Node.js 22 или новее (рекомендуется 24).  
```  
npm start    
   
```  
Открыть http://127.0.0.1:4173. Для остановки нажать Ctrl+C в терминале.  
 Если PowerShell запрещает npm.ps1, использовать `npm.cmd start` или `node server/index.mjs`.  
   
    
   
  **Необязательный Cohere**  
   
    
   
  Создать `.env` в корне проекта по `.env.example`:  
```  
COHERE_TRIAL_KEY=ваш_ключ      
   COHERE_MODEL=command-r7b-12-2024      
   PORT=4173      
         
      
   
```  
Доступность модели и лимиты зависят от аккаунта Cohere; при необходимости заменить COHERE_MODEL на доступную совместимую модель.  
   
    
   
  Сначала запрос разбирают локальные слова, синонимы и темы. Cohere вызывается только по кнопке «Подобрать», когда локальный подбор не уверен и включён переключатель. Отправляются только текст до 240 символов, краткая инструкция и десять пар `ID:название`. Файлы, SVG, картинки, история диалога и содержимое сцены не отправляются.  
   
    
   
  Ответ ограничен 100 выходными токенами и четырьмя разрешёнными ID. Таймаут — 12 секунд; автоматических повторов нет. Интервал между новыми вызовами — 6 секунд, максимум 10 вызовов за запуск локального сервера (на Vercel — за время жизни экземпляра функции). Локально ответы сохраняются в `.cache/interpret.json`, на Vercel — только в памяти экземпляра функции: повторный запрос не расходует новый вызов. Текст запросов остаётся в этом локальном кеше; каталог `.cache` исключён из Git. Без ключа доступны локальные запросы и ручная сборка. Реальный API не используется в тестах.  
   
    
   
  Документация интеграции: \[[https://docs.cohere.com/v2/reference/chat  
   
  ](https://docs.cohere.com/v2/reference/chat "https://docs.cohere.com/v2/reference/chat")  
1. Ввести «Собрать знания воедино» и нажать «Подобрать» — локально выбираются книга и пазлы.  
2. Выбрать квадратный, альбомный или портретный холст; переключить L/S.  
3. Нажать на объект библиотеки, перетащить его на холсте, выбрать роль, повернуть, дублировать или изменить слой.  
4. Выбрать другую палитру. Для новой схемы скачать пример JSON, изменить цвета и загрузить его.  
5. Нажать «Скачать SVG». Каждый предмет экспортируется отдельной векторной группой.  
6. «Сохранить проект» выгружает JSON сцены и палитр; «Открыть» восстанавливает его. Последняя сцена автоматически сохраняется в браузере.  
   
    
   
 Готовые примеры композиций в формате SVG находятся в `examples/`.  
   
  **Архитектура**  
- `public/assets/` — копии исходных SVG без изменения геометрии; `catalog.json` связывает стабильный ID с четырьмя вариантами L/S × main/background, тегами и эталонными габаритами.  
- `public/js/scene.js` — чистая модель композиции, локальный подбор, алгоритм размещения, палитры и SVG-экспорт. Алгоритм выбирает сетку с максимальным общим масштабом; варианты дают смещение или свободную область под заголовок.  
- `public/js/app.js` — интерфейс, перетаскивание, операции над объектами, отмена/повтор, импорт и сохранение проекта.  
- `server/index.mjs` — локальный HTTP-сервер, раздающий только `public/`; проверяет Origin и размер запросов.  
- `server/interpret.mjs` — минимальный адаптер Cohere с валидацией, кешем и ограничениями расхода.  
- `scripts/prepare-assets.py` — воспроизводимая подготовка каталога из библиотеки компонентов. Скрипт автономен и не зависит от служебных файлов. Для обычного запуска исходная папка не требуется.  
   
    
   
  **Проверки**  
```  
npm test      
         
      
   
```  
Тесты проверяют размещение 1–12 объектов, общий масштаб, варианты форматов, локальный подбор, палитры, векторный экспорт, реальные ассеты и защиту API. Cohere заменён тестовым fetch: ключ и trial-квота не используются.
